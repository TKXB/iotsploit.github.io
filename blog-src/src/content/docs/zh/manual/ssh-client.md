title: SSH 终端与 SFTP

**SSH Client** 用于连接远程主机、打开交互式终端会话，并通过 SFTP 上传和下载文件。SSH 协议和 SFTP 子系统由应用内置实现，不会调用外部 SSH 程序。

:::caution[授权]
仅连接你拥有或获得授权的主机。SSH Client 不验证服务器主机密钥（详见[主机密钥处理](#主机密钥处理)），因此无法检测中间人攻击。请在可信网络环境中使用此工具；若目标较为敏感，请通过带外方式核对服务器指纹。
:::

## 前置条件

- **平台**：仅限原生构建（Android、iOS、macOS、Windows、Linux）。Web 构建中不可见，因为依赖 Rust 原生代码。
- **构建**：生产、开发、离线三种 flavor 均可用。工具目录中标记为 `offlineCapable: true`、`prodCapable: true`。
- **服务器**：不需要。SSH Client 从设备直接连接目标 SSH 服务器，不经过 IoTSploit API 服务器。
- **网络**：设备必须能访问目标主机的 SSH 端口（默认 22）。防火墙、NAT 或网络隔离会影响连接。

## 打开 SSH Client

1. 打开 IoTSploit 应用。
2. 在侧边栏选择 **Toolkit**。
3. 找到 **SSH Client** 卡片（描述为 "Secure shell client powered by rust"），点击进入。

屏幕先显示连接表单。连接成功后，表单切换为终端视图，包含状态栏和传输控件。

## 建立连接

### 连接表单

| 字段 | 默认值 | 说明 |
|---|---|---|
| Host | `127.0.0.1` | 主机名或 IP 地址 |
| Port | `22` | 1–65535 |
| Username | `root` | 任意有效的 SSH 用户名 |
| Authentication | Password | 下拉选择：Password、Public Key、None |

### 认证方式

| 方式 | 字段 | 说明 |
|---|---|---|
| Password | 密码 | 密码输入框，内容不可见 |
| Public Key | PEM 私钥、口令（可选） | 在等宽文本框中粘贴 PEM 格式的私钥。口令仅在非空时发送。 |
| None | — | 调用 `authenticate_none`。适用于无认证的服务器或测试场景。 |

### 最近目标

连接成功后，目标信息（主机、端口、用户名）会存入 SharedPreferences，键为 `ssh_client.recent_targets.v1`。最多保留 5 条，以芯片形式显示在表单下方。点击芯片可自动填充主机、端口和用户名。

### Connect 按钮

点击 **Connect**。按钮显示 `Connecting...` 和加载动画，期间不可再次点击。连接超时为 10 秒——若服务器在此时限内未响应，错误信息为 `Connection timed out`。

### 输入校验

| 检查项 | 错误信息 |
|---|---|
| Host 为空 | `Please enter a host address.` |
| Port 非数字或超出 1–65535 | `Invalid port (1-65535).` |
| Username 为空 | `Please enter a username.` |

### 连接结果

成功后，屏幕切换到终端视图。状态栏显示：

- 绿色状态指示点。
- 连接字符串（桌面端为 `user@host:port`；移动端端口为 22 时省略，显示 `user@host`）。
- 服务器横幅——主机密钥类型与 SHA-256 指纹，格式为 `<算法> (<sha256-fingerprint>)`。
- 远程工作目录（CWD）芯片。

失败时，表单下方出现错误卡片，信息来自 Rust 侧：

| 失败原因 | 信息 |
|---|---|
| TCP 连接错误 | `Connection failed: <错误>` |
| 超时 | `Connection timed out` |
| 认证被拒 | `Authentication failed` |

## 终端

终端是全功能 PTY shell，支持 10,000 行回滚，使用 JetBrains Mono 等宽字体。

### 终端类型

PTY 请求的终端类型为 `xterm-256color`。传入服务器的行列数取自连接时终端视口的尺寸。

### 键盘输入

**桌面端**（macOS、Windows、Linux、Web）：通过全局键盘监听器捕获按键并转发到终端。剪贴板快捷键被拦截，不会发送到远程 shell：

| 操作 | 快捷键 |
|---|---|
| 复制 | Ctrl+Shift+C（Linux/Windows/Web）或 Cmd+C（macOS） |
| 粘贴 | Ctrl+V 或 Ctrl+Shift+V（Linux/Windows/Web）或 Cmd+V（macOS） |

其余按键——包括 Ctrl+C（SIGINT）、Ctrl+D（EOF）、Ctrl+Z（挂起）、方向键、功能键——均直接发送到远程 shell。

**移动端**（Android、iOS）：屏幕键盘上方显示一个工具栏，提供以下按键：

| 按键 | 发送内容 | 用途 |
|---|---|---|
| Esc | `0x1B` | 取消 / 退出 |
| Tab | `0x09` | 自动补全 |
| Ctrl | 打开菜单 | Ctrl+C（SIGINT）、Ctrl+D（EOF）、Ctrl+Z（挂起）、Ctrl+L（清屏）、Ctrl+R（历史搜索）、Ctrl+A（行首）、Ctrl+E（行尾）、Ctrl+U（删行）、Ctrl+W（删词） |
| Alt | 打开菜单 | Alt+B（向前跳词）、Alt+F（向后跳词）、Alt+.（上一条参数）、Alt+D（向后删词） |
| / | `/` | 正斜杠 |
| `\|` | `\|` | 管道符 |
| ← ↑ ↓ → | ANSI 转义序列 | 方向键 |

### 终端尺寸调整

当终端视口尺寸变化（窗口缩放、屏幕旋转），新的行列数通过 `windowchange` PTY 消息发送到服务器，使远程 shell 的换行与可见终端保持同步。

### 会话生命周期

- **Disconnect 按钮**：取消所有进行中的传输，向服务器发送断开请求，返回连接表单。
- **服务器关闭**：服务器关闭连接或流结束时，终端标记会话已结束并返回表单，显示 `Session ended: <error>`。
- **页面销毁**：离开页面时，会话被断开，所有传输订阅被取消。

## SFTP 文件传输

SSH Client 内置双向 SFTP，支持上传（Push）和下载（Pull）。SFTP 在同一 SSH 会话上通过独立通道运行——终端与 SFTP 通道不共享目录状态。

### Push（上传）

1. 点击状态栏中的 **Push**（上传图标）。
2. 打开文件选择器。桌面端可多选；移动端选中的文件会先复制到应用临时目录，以便 Rust 上传器获得稳定的文件路径。
3. 每个文件上传到 `<远程当前目录>/<文件名>`。
4. 传输出现在传输面板中，显示进度条和速度。
5. 完成后，终端回显一行：`[scp] ↑ uploaded <文件名> → <远程路径>`。

### Pull（下载）

1. 点击状态栏中的 **Pull**（下载图标）。
2. 弹出远程文件选择器，显示当前远程目录的内容。
3. 点击文件夹进入子目录，点击 `.. (parent)` 返回上级。
4. 点击文件选中。桌面端弹出原生保存对话框选择目标路径；移动端保存到应用文档目录。
5. 传输出现在传输面板中。
6. 完成后，终端回显一行：`[scp] ↓ downloaded <文件名> → <本地路径>`。移动端还会弹出 SnackBar 提示 `Saved to <本地路径>`。

### 传输状态

| 状态 | 指示 | 说明 |
|---|---|---|
| 进行中 | 上传/下载箭头、进度条、百分比 | 可取消 |
| 完成 | 绿色对勾、满进度条 | 显示 `Done` |
| 已取消 | 错误色图标 | 显示 `Cancelled` |
| 错误 | 错误色图标 | 显示 `Error`，SnackBar 显示错误信息 |

### 传输面板

- **桌面端**：终端上方出现内嵌面板，显示进行中和完成的数量、"Clear completed" 按钮以及传输行列表（文件名、远程路径、速度、进度条、百分比）。
- **移动端**：终端底部浮出悬浮面板，可折叠展开。传输行更为紧凑。
- 传输列表最多保留 20 条。新传输会挤出旧记录。

### 取消传输

每个进行中的传输可单独取消。取消操作设置一个取消标志——传输循环在每次读取块之间检查该标志并中止。上传和下载的 `.part` 临时文件都会被删除。断开 SSH 连接会取消所有进行中的传输。

## 远程工作目录

状态栏中的 CWD 芯片显示 Push 和 Pull 操作的当前远程目录。有两种模式：

### 跟随终端 CWD

启用时（默认），每 2 秒刷新一次 CWD：发现终端 shell 进程并解析其工作目录。切换按钮在跟随时显示同步图标，手动模式显示禁用同步图标。

工作原理：

1. 在远程主机上执行 `ps -eo pid=,ppid=,tpgid=,tty=,etimes=`。
2. 找到最新的 PTY（即分配给当前 SSH 会话的那个）。
3. 在该 PTY 上找到前台进程组 leader——即提示符处活动的 shell。
4. 通过 SFTP `canonicalize` 解析 `/proc/<pid>/cwd`。

此功能需要 Linux 目标，且 `/proc` 文件系统和 `ps` 命令可用。在非 Linux 目标或 `/proc` 不可用时，CWD 保持在最后一次已知值，或回退到 `.`（服务器默认目录）。

### 手动 CWD

点击 CWD 芯片打开对话框，输入路径。路径通过 `sshSftpRealpath`（SFTP `canonicalize`）解析，同时关闭跟随模式。适用于进程发现不可用的目标。

### 初始 CWD 解析

连接成功后，客户端尝试通过 `sshSftpRealpath(path: '.')` 解析家目录。若服务器未启用 SFTP，此调用静默失败，CWD 保持在 `.`——芯片显示 `~ (server default)`。实际使用 Push/Pull 时会给出更明确的错误。

## 主机密钥处理

SSH Client **接受所有服务器主机密钥**，不做任何验证。密钥类型和 SHA-256 指纹会被捕获并显示在状态栏中，但不会与已知主机数据库比对。

这是为了在嵌入式和 IoT 测试场景中获得更好的可用性而做出的权衡——这些场景中 rarely 有 known_hosts 文件，且主机密钥经常变化。代价是客户端无法检测中间人攻击。如需主机密钥验证，请使用标准 SSH 客户端并启用 `StrictHostKeyChecking`。

## 局限性

- **不验证主机密钥。** 所有服务器密钥均被接受。详见[主机密钥处理](#主机密钥处理)。
- **无已知主机管理。** 没有 `known_hosts` 文件，没有 TOFU（首次使用即信任），也没有跨会话指纹比对。
- **不支持代理转发。** 不支持 SSH agent forwarding。
- **不支持端口转发。** 本地、远程和动态端口转发均未实现。
- **不使用 SCP 协议。** 文件传输仅通过 SFTP。终端回显行中的 `[scp]` 前缀是装饰性标签，并非 SCP 协议消息。
- **CWD 跟踪仅限 Linux。** 通过 `ps` 和 `/proc` 的进程发现仅适用于 Linux 目标。在 macOS、BSD 或其他目标上，请使用手动 CWD 输入。
- **单会话。** 同一时间只能维持一个 SSH 会话。新建连接会断开前一个。
- **无会话持久化。** 断开连接或离开页面即结束会话。不支持重连或会话恢复。
- **连接超时固定为 10 秒。** 无法在界面中修改。
- **移动端文件暂存。** 移动平台上，选中的文件在上传前会复制到应用临时目录。大文件会占用临时存储空间，直到上传完成或失败。
- **需要 SFTP 子系统。** 若 SSH 服务器未启用 SFTP 子系统，Push 和 Pull 将失败。CWD 解析也会静默失败——芯片显示 `~ (server default)`。

## 故障排除

### Toolkit 页面看不到 SSH Client 卡片

你在使用 Web 构建。SSH Client 依赖 Rust 原生代码，Web 构建不会编译。请使用原生构建。

### `Connection timed out`

服务器在 10 秒内未响应。检查主机和端口，确认网络可达，确认 SSH 服务正在运行。设备与目标之间的防火墙可能丢弃了连接。

### `Connection failed: <错误>`

TCP 连接已建立，但 SSH 握手或认证失败。常见原因：端口错误、该端口上运行的不是 SSH 服务、或协议不匹配。

### `Authentication failed`

服务器拒绝了凭据。密码认证请检查密码；公钥认证请确认 PEM 有效且对应公钥已在服务器的 `authorized_keys` 中；`none` 认证需要服务器显式允许（大多数不允许）。

### 连接后终端无输出

Shell 可能未启动，或服务器发送了终端无法解码的数据。终端会尽可能解码输出，无效字节会被替换而非崩溃。若服务器发送二进制数据或 shell 非交互式，可能看不到输出。尝试按回车或运行 `ls` 等命令。

### CWD 芯片显示 `~ (server default)`

SFTP realpath 失败——服务器未启用 SFTP，或初始解析失败。Push 和 Pull 仍会尝试从服务器默认起始目录操作。若 SFTP 不支持，传输会报错。

### 在终端 `cd` 后 CWD 不更新

目标可能不是 Linux，或 `/proc` 不可用。CWD 跟踪依赖 `ps` 输出和 `/proc/<pid>/cwd` 解析。点击 CWD 芯片手动输入路径，或关闭再开启跟随模式。

### 上传报重命名错误

OpenSSH 的 SFTP 服务器在目标已存在时拒绝 rename。上传器会先尽力删除目标文件，但若服务器不允许（权限、文件锁定），rename 会失败。请先手动删除远程已有文件，或上传到不同路径。

### 移动端下载保存位置不对

移动端下载文件会保存到应用文档目录（`getApplicationDocumentsDirectory()`）。路径会在 SnackBar 和终端回显中显示。使用文件管理器或系统分享面板访问该文件。

### 传输从列表中消失

传输列表最多保留 20 条。新传输会挤出旧记录。已完成的传输也可通过 "Clear completed" 按钮（桌面端）或断开连接来清除。

### `Session ended: <错误>`

服务器关闭了连接、网络中断，或 SSH 保活在 3 次未响应（45 秒）后失败。重新连接即可恢复。

## 推荐工作流

1. 打开 **Toolkit**，选择 **SSH Client**。
2. 填写主机、端口、用户名，选择认证方式。
3. 点击 **Connect**。核对服务器横幅中的指纹是否符合预期。
4. 根据需要使用终端。移动端可用键盘工具栏发送控制键。
5. 上传文件点 **Push**，从本地选择器选文件。
6. 下载文件点 **Pull**，在远程文件选择器中导航。
7. 在面板或悬浮面板中监控传输，必要时取消。
8. 完成后点 **Disconnect**。这也会取消所有进行中的传输。

如需 CAN 总线帧分析，请继续阅读 [CAN analysis](/blog/zh/manual/can-analysis/)。
